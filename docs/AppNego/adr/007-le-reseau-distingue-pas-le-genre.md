# ADR-007 — C'est le réseau qui distingue, pas le genre

**Statut** : accepté — 18/09/2026

## Contexte

Tout ce qu'une négociatrice peut faire, un négociateur le peut aussi. Il faut pourtant les distinguer : le réseau des négociatrices formées par l'IFDD a son groupe, et les bailleurs demandent des chiffres. La civilité du compte ne suffit pas — elle peut valoir « Dr » ou « Pr ».

## Décision

Aucun champ « genre » ne commande un droit. Ce qui distingue une négociatrice est son **appartenance au réseau**, portée par le code d'invitation diffusé dans son groupe.

## Conséquences

- Mêmes droits pour toutes et tous ; le réseau ajoute seulement son canal réservé.
- Un code par public : celui du réseau des négociatrices, celui des négociateurs en général.
- Les chiffres pour les bailleurs se tirent de l'appartenance au réseau.
- Personne n'a de case à cocher sur son identité.
