Un message de la régie se lit là où l'on regarde déjà : dans le billet de l'activité concernée, qui reste à l'écran quand on fait défiler la page, et sur sa carte dans le programme. Seul un message qui vaut pour toute l'édition prend une bande sous la barre de navigation. Il n'y a plus de bandeau au-dessus de la photo, qu'on ne voit pas une fois la page défilée.

Trois niveaux, selon ce que ça change

La nature du message choisit le niveau ; la régie peut le changer. Un retard de dix minutes est une information : l'activité a bien lieu.

Information

L'activité a lieu ; un détail change. Fond cyan pâle, se referme.

  • Retard
  • Changement d'horaire
  • Changement de salle
  • Information libre

Attention

Le visiteur peut être gêné. Fond jaune pâle, ne se referme pas.

  • Débordement sur le créneau suivant
  • Problème de connexion
  • Absence d'un intervenant

Interruption

L'activité ne se suit pas. Aplat rouge, ne se referme pas.

  • Direct interrompu (problème technique)
  • Annulation
