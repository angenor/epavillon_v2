# Tutoriel 1 : ajouter l'image de couverture de son activité

Public : la personne d'une organisation qui a une activité retenue. Durée visée : 2 min 10.
Tournage : site local, données fictives, compte de démonstration, thème clair, 1920 × 1080.
Voix : un fichier par scène (`s1.mp3` … `s7.mp3`), l'animation se cale sur leur durée.

## Découpage

| Scène | Ce qu'on voit | Mise en valeur |
|-------|---------------|----------------|
| 1. Pourquoi | L'image de couverture sur la page publique d'une activité, puis un lien partagé avec son aperçu | Titre « Ajouter l'image de couverture » |
| 2. Où | « Mon organisation », la carte « À faire », la ligne « L'image de couverture » | Zoom sur « Ajouter » |
| 3. Deux façons | Le dossier, rubrique « Image de couverture », ses deux boutons | Étiquettes « Façon 1 : un modèle » et « Façon 2 : votre image » |
| 4. Façon 1, le modèle | Clic sur « Créer ou choisir un modèle », atelier, onglet « Modèles », trois modèles essayés, une couleur, « Sur l'image » | Zoom sur la liste des modèles puis sur l'aperçu |
| 5. Façon 1, enregistrer | Onglet « Textes » survolé, « Enregistrer la couverture », message « Image de couverture enregistrée », retour au dossier | Zoom sur le bouton vert |
| 6. Façon 2, votre image | « Changer l'image », choix du fichier, recadrage au format 16:9, description, « Téléverser », message de préparation | Cadre de recadrage mis en valeur |
| 7. Fin | La page publique avec la nouvelle image | Rappel : « Mon organisation → votre dossier → Image de couverture » |

## Texte de la voix off

**Scène 1** (12 s)
L'image de couverture illustre votre activité sur la plateforme. C'est aussi elle qui s'affiche quand quelqu'un partage le lien de votre activité.

**Scène 2** (14 s)
Pour l'ajouter, ouvrez « Mon organisation ». Tant que l'image manque, elle figure dans « À faire ». Cliquez sur « Ajouter ».

**Scène 3** (12 s)
Vous arrivez dans votre dossier, à la rubrique « Image de couverture ». Deux façons de faire : partir d'un modèle, ou déposer votre propre image.

**Scène 4** (30 s)
Commençons par les modèles. Cliquez sur « Créer ou choisir un modèle ». Les modèles sont préparés par l'IFDD, aux couleurs de la Francophonie. Le titre, la date, le lieu et les intervenants de votre activité sont déjà en place. Cliquez sur un modèle : l'image change aussitôt. Choisissez une couleur, puis ce qui apparaît sur l'image : la date, les intervenants, le logo de votre organisation.

**Scène 5** (18 s)
Le titre est trop long sur l'image ? Raccourcissez-le dans l'onglet « Textes ». Quand l'image vous plaît, cliquez sur « Enregistrer la couverture ». Elle s'affiche dans votre dossier, et vous pourrez la modifier quand vous voudrez.

**Scène 6** (30 s)
Vous avez déjà votre propre visuel ? Dans le dossier, cliquez sur « Changer l'image » et choisissez votre fichier. L'image doit être au format paysage, 16 sur 9 : déplacez le cadre pour garder l'essentiel. Vous pouvez décrire l'image en une phrase, pour les personnes qui ne la voient pas. Cliquez sur « Téléverser ». Après quelques secondes de préparation, l'image s'affiche partout.

**Scène 7** (10 s)
Et voilà : votre activité a son image. Pour la changer, il suffit de revenir dans votre dossier, rubrique « Image de couverture ».
